AWS + Linux Combo — Part 4: Storage, EBS & Mounts

Storage mistakes can crash production systems. Linux storage understanding is mandatory on AWS.

What is EBS?

EBS is a virtual hard disk attached to EC2.

Check Disks


lsblk
df -h

Create Filesystem


sudo mkfs.ext4 /dev/xvdf

Mount Volume


sudo mkdir /data
sudo mount /dev/xvdf /data

Permanent Mount


/dev/xvdf /data ext4 defaults 0 0

Backups Matter

AWS snapshots are useless if Linux data layout is wrong.
