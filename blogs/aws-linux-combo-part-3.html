AWS + Linux Combo — Part 3: Users, Permissions & SSH Security

Running everything as root is dangerous. Real servers use proper Linux users.

Create a New User


sudo adduser devuser

Give Sudo Access


sudo usermod -aG sudo devuser

Switch User


su - devuser

File Permissions Explained


ls -l
chmod 755 file.sh
chown user:user file.sh

SSH Security Basics

  • Disable root login
  • Use key-based auth only
  • Change default SSH port (optional)

Why This Matters

Most cloud hacks happen due to weak Linux permissions. AWS cannot save you from bad Linux practices.
